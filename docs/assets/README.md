# README artwork

## Elephant library banner

`elephant-library.png` was generated for this project using the built-in OpenAI
image generation tool on October 7, 2026. It is illustrative artwork, not a
screenshot of the application. No reference images were supplied.

### Generation prompt

> Use case: illustration-story
> Asset type: a polished wide GitHub README banner for the Pachyderm Library AI evaluation project.
> Primary request: a calming elephant quietly reading a book in a peaceful library.
> Subject and scene: one gentle elephant librarian resting beside a low stack of books, a few softly suggested shelves, warm natural window light. Friendly, thoughtful, dignified, inviting.
> Style: refined hand-painted editorial illustration with soft watercolor and subtle paper grain, uncluttered composition, muted colors, generous breathing room. Wide landscape banner, elephant and reading nook as the visual focus, details remain legible at README width.
> Constraints: no lettering or text, no logos, no watermark, no other characters.
