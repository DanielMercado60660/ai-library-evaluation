### Hanno Memorial Library Idea Bank: Elephant-Punny Generation Fuel

- **Key Rules Recap**: Keep summaries **sparse** (e.g., just high-level setup, no plot twists, character names beyond titles, morals, or endings – perfect for hallucination traps). Avoid real-world book/author collisions. Use consistent eras (Founding Age for legends, Ivory Renaissance for verse tragedies, etc.). Cross-reference existing books/authors/houses/events for internal logic (e.g., link to Border Wars or Hanno the Elder). ISBNs deterministic (978-0-HANNO-XXXX for core HML, 978-0-GHLS-XXXX for extended). Strata-specific tones/styles (e.g., Shakespearean gravity for I, whimsical for V). No full plots – models should have to "invent" details.
  
- **Generation Method Tips**: Batch ~50 at a time for quality. Use deterministic elements (IDs, page counts ~200-300 for adults, 20-100 for kids; conditions like "good"/"fragile"). LLM for creative parts (titles/summaries), but freeze canon once generated. Mix with noble/academic/warm names. For parodies, subtly riff on classics without direct copies.

### Indo-European / South Asian (Hindi, Sanskrit, Tamil, etc.)
- **Sanskrit**: Gaja (GAH-jah) — most common; Hasti (HAS-tee) — "having a hand" (trunk reference); Mātaṅga (MAA-tung-gah) — poetic/mythic; Airāvata (eye-RAH-vah-tah) — Indra's divine white elephant (rainbow/lightning symbol).
- **Hindi**: Hāthī (HAA-thee) — everyday word; Gaj (guj) — formal/literary.
- **Tamil**: Yāṉai (YAA-nai) — common; Āṇai (AA-nai) — variant.
- **Other Indic**: Āne (Kannada: AA-nay), Hāti (Bengali: HAA-tee), Gajah (Indonesian/Malay borrowing).

→ Pun potential: Gaja → "Gajahorn" (noble house); Airāvata → "Airavelle" (mythic tragedy title); Hasti → "Hastivane" (scholarly author).

### Southeast Asian / Thai / Burmese
